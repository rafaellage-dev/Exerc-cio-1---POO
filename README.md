# Exercicio-1-POO
Exercício avaliativo número 1 da disciplina de Programação Orientada a Objetos. Nesse exercício foi proposta a criação de um programa em Java que pedisse um número inteiro positivo e calculasse a tabuada de 1 a 10 desse número, seguindo 3 regras adicionais:
1. Se o usuário digitar um número negativo, o programa deve exibir uma mensagem de erro: "Número inválido. Por favor, digite um número maior que zero.";
2. Ao imprimir a tabuada, o programa deve informar, ao lado de cada resultado, se aquele valor é "Par" ou "Ímpar";
3. O programa deve rodar de forma infinita e mostrar tabuadas até o usuário digitar 0 para finalizar.

O exercício foi desenvolvido usando o Visual Studio Code, onde foram criados dois arquivos: o primeiro (Main.java) contém a estrutura principal do código, enquanto o segundo arquivo (ConsoleUtils.java) é um método criado para limpar as tabuadas e frases passadas escritas no terminal a cada repetição do loop.
